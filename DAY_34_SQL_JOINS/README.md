# 📅 Day 34 – SQL Joins

> **100 Days of Code | SQL Journey**

Today, I learned one of the most important SQL concepts: **Joins**. Joins allow data from multiple related tables to be combined, making it possible to retrieve meaningful information from relational databases.

---

# 📚 Topics Covered

## 1️⃣ Introduction to Joins

Learned:

- What is a JOIN?
- Why joins are used in relational databases
- How related tables communicate using Primary Keys and Foreign Keys

---

## 2️⃣ INNER JOIN

Practiced retrieving only matching records from multiple tables.

### Examples

- Product with Supplier
- Product with Orders
- Supplier with Inventory Orders

---

## 3️⃣ LEFT JOIN

Learned how to retrieve:

- All records from the left table
- Matching records from the right table
- NULL values for unmatched records

---

## 4️⃣ RIGHT JOIN

Learned how to retrieve:

- All records from the right table
- Matching records from the left table

---

## 5️⃣ FULL OUTER JOIN

Practiced combining:

- LEFT JOIN
- RIGHT JOIN

using UNION to simulate FULL OUTER JOIN in MySQL.

---

## 6️⃣ SELF JOIN

Learned how to join a table with itself.

Practiced:

- Employee → Manager relationship
- Hierarchical data

---

## 7️⃣ CROSS JOIN

Learned how to generate every possible combination between two tables.

---

# 💻 Hands-on Database

Used the previously created **Product Inventory Database** consisting of:

- Supplier
- Product Details
- Inventory Orders

Applied all join operations on this relational database.
