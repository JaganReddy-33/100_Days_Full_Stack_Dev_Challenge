# 📅 Day 29 – SQL Data Retrieval & Filtering

> **100 Days of Code | SQL Journey**

Today, I focused on mastering SQL queries used for retrieving, filtering, sorting, and searching data. These concepts form the foundation of writing efficient database queries for real-world applications.

---

# 📚 Topics Covered

## 1️⃣ SELECT

Learned how to retrieve data from database tables.

### Practiced

- Select all columns
- Select specific columns
- Column aliases using `AS`
- Arithmetic operations in SELECT

Examples:

- Retrieve complete table data
- Retrieve selected columns
- Rename output columns
- Calculate values within queries

---

## 2️⃣ WHERE

Learned how to filter records based on conditions.

### Comparison Operators

- =
- >
- <
- >=
- <=
- <>
- !=

### Logical Operators

- AND
- OR
- NOT

### NULL Handling

- IS NULL
- IS NOT NULL

Practiced filtering data using single and multiple conditions.

---

## 3️⃣ ORDER BY

Learned how to sort query results.

### Practiced

- ASC (Ascending)
- DESC (Descending)
- Sorting by multiple columns
- Sorting using aliases

---

## 4️⃣ DISTINCT

Learned how to eliminate duplicate records.

### Practiced

- DISTINCT on a single column
- DISTINCT on multiple columns

---

## 5️⃣ LIKE Operator

Learned pattern matching using SQL wildcards.

### Wildcards Covered

- `%` (Zero or More Characters)
- `_` (Exactly One Character)

Practiced queries for:

- Starts with
- Ends with
- Contains
- Fixed-length patterns

---

## 6️⃣ Regular Expressions (REGEXP)

Explored advanced pattern matching using SQL REGEXP.

### Practiced

- Beginning of string (`^`)
- End of string (`$`)
- Character ranges
- Alternatives (`|`)
- Character classes

Built multiple queries to match names, emails, phone numbers, and custom text patterns.

---

## 7️⃣ REGEXP Query Practice

Solved real-world SQL queries using regular expressions.

Examples included:

- Names starting with a specific letter
- Email pattern matching
- Numeric values
- Product name searches
- Employee data filtering

# 🧠 Key Learnings

- Retrieve only the required data using SELECT.
- Filter records efficiently with WHERE.
- Sort results using ORDER BY.
