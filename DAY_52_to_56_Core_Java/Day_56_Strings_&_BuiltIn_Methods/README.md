## 🧠 Key Learnings

* Strings in Java are objects of the `String` class.
* String literals are stored in the String Pool.
* `new String()` creates a separate String object.
* Strings are immutable.
* String methods generally return a new String instead of modifying the original String.
* `==` compares object references, while `equals()` compares String content.
* `compareTo()` performs lexicographical comparison.
* `indexOf()` and `lastIndexOf()` are useful for locating characters and substrings.
* `replace()` can replace characters or literal strings.
* `replaceAll()` works with regular expressions.
* `substring()` is useful for extracting portions of a String.
* `trim()` and `strip()` can remove surrounding whitespace.
