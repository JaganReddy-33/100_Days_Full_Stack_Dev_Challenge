
# 📅 Day 31 – SQL Control Flow & Window Functions

> **100 Days of Code | SQL Journey**

Today, I explored SQL Control Flow and Window Functions—powerful features used in data analysis, reporting, and business intelligence. These concepts help write cleaner queries, perform row-wise calculations, and generate rankings without grouping data.

---

# 📚 Topics Covered

## 1️⃣ IF() Function

Learned how to implement conditional logic directly within SQL queries.

### Practiced

- IF() with numeric conditions
- IF() with text values
- Nested IF()
- IF() inside SELECT statements

---

## 2️⃣ CASE Statement

Learned how to handle multiple conditions using CASE expressions.

### Practiced

- Simple CASE
- Searched CASE
- Multiple conditions
- CASE with ORDER BY
- Grade classification examples

---

## 3️⃣ Window Functions

Understood how Window Functions perform calculations across rows without collapsing the result set.

### Concepts Covered

- OVER()
- PARTITION BY
- ORDER BY within OVER()

---

## 4️⃣ ROW_NUMBER()

Learned how to generate sequential row numbers.

### Practice

- Department-wise numbering
- Ordered numbering
- PARTITION BY usage

---

## 5️⃣ RANK()

Learned ranking with gaps when duplicate values exist.

### Practice

- Salary ranking
- Student ranking
- Department rankings

---

## 6️⃣ DENSE_RANK()

Learned ranking without gaps for duplicate values.

### Practice

- Employee ranking
- Student ranking
- Comparison with RANK()

---

## 7️⃣ LAG() & LEAD()

Learned how to access previous and next row values.

### Practice

- Previous month's sales
- Next month's sales
- Comparing consecutive records
- Trend analysis
