````markdown
# ☕ 100 Days of Code — Day 55
## Core Java — 2D Arrays, Multidimensional Arrays & Jagged Arrays

> **Focus:** Understanding two-dimensional and multidimensional arrays, matrix operations, and jagged arrays through practical Java programs.

---

## 🎯 Day 55 Objective

The goal of Day 55 was to move beyond one-dimensional arrays and understand how Java handles **2D arrays, multidimensional arrays, matrix operations, and jagged arrays**.

The focus was on learning how to work with rows and columns, traverse matrices using nested loops, and solve different matrix-based programming problems.

---

## 1. 2D Arrays

Learned the fundamentals of two-dimensional arrays:

- What is a 2D array?
- Declaration
- Initialization
- Using the `new` keyword
- Rows and columns
- Index-based access
- Updating elements
- Understanding `.length` for rows and columns

## 2. Accessing & Updating Elements

Practiced accessing individual matrix elements using row and column indexes.
````

Also practiced updating existing elements inside a 2D array.

* Number of rows

* Accessing individual columns

* Column-wise processing

```text

        ↓
```

# ✖️ 8. Matrix Multiplication

Practiced matrix multiplication using nested loops.

The operation requires:

* Taking rows from the first matrix
* Taking columns from the second matrix
* Multiplying corresponding elements
* Adding the products
* Storing the result in the resulting matrix

This helped strengthen nested-loop logic and matrix indexing.

---

# 🔄 9. Matrix Transpose

Learned how to transpose a matrix by converting:

```text
Rows → Columns
Columns → Rows
```

Example concept:

```text
Original Matrix

1  2  3
4  5  6

Transpose

1  4
2  5
3  6
```

---

# 🔹 10. Diagonal Operations

Practiced working with matrix diagonals.

### Main Diagonal

Elements where the row index and column index are the same.

```text
[1]  2   3
 4  [5]  6
 7   8  [9]
```

### Secondary Diagonal

Practiced identifying and processing the opposite diagonal.

Also practiced diagonal-related calculations.

---

# 🟦 11. Identity Matrix

Learned the concept of an identity matrix.

An identity matrix contains:

* `1` on the main diagonal
* `0` everywhere else

Example:

```text
1 0 0
0 1 0
0 0 1
```

Practiced checking whether a given matrix is an identity matrix.

---

# 🔄 12. Symmetric Matrix

Learned the concept of a symmetric matrix.

A matrix is symmetric when it remains the same after transposition.

```text
Matrix == Transpose(Matrix)
```

Practiced checking whether a matrix satisfies this condition.

---

# 🔺 13. Triangular Matrices

Covered triangular matrix concepts and practiced examples.

### Upper Triangular Matrix

Elements below the main diagonal are zero.

### Lower Triangular Matrix

Elements above the main diagonal are zero.

Practiced identifying and checking these matrix structures.

---

# 🧩 14. Multidimensional Arrays

Extended the understanding of 2D arrays to multidimensional arrays.

Covered:

* Multidimensional array structure
* Declaration and initialization
* Accessing elements
* Nested-loop traversal
* Working with multiple dimensions

---

# 🪜 15. Jagged Arrays

Learned about **jagged arrays**, where each row can have a different number of elements.

Example:

```text
Row 1 → 3 elements
Row 2 → 5 elements
Row 3 → 2 elements
```

Unlike a traditional rectangular matrix, every row does not need to have the same length.

Practiced:

* Declaration
* Initialization
* Creating rows with different sizes
* Accessing elements
* Traversing jagged arrays
* Practical examples
